# Replication — Participatory Science on the Farm (2023 analysis + disparity over time)

A small, step-through set of scripts that regenerate the paper's findings. The single-year
scripts (01–04) run in the cloud (Google Earth Engine + the GBIF Maps API); the decade series
(05–06) rebuilds from two included panels in seconds. Nothing large is downloaded.

## Setup (one time)
1. **Python environment** (Python 3.9+). Install:
   ```
   pip install earthengine-api requests pyarrow geopandas matplotlib mapbox-vector-tile mercantile
   ```
2. **Google Earth Engine**: `earthengine authenticate` once. The scripts call `ee.Initialize()`.
   (Only steps 01–04 and the `generators/` scripts need Earth Engine. Steps 05–06 do not.)

## Run order (step through top to bottom)
| Script | What it shows | Runtime | Expected result |
|---|---|---|---|
| `01_ag_area_2023.py` | % of CONUS that is farmland (NLCD 81+82) | ~1 min | **~23.9%** |
| `02_obs_disparity_2023.py` | % of observations on farmland + CONUS disparity (coarse ~137 m grid) | ~5–10 min | **~9.5% on ag; disparity ~2.5×** |
| `03_county_disparity_2023.py` | share of counties under-observing farmland + figure | ~2 min | **~78% of counties (disparity > 1)** |
| `04_coverage_2023.py` | % farmland within 1 km of an observation | ~1 min | **~25% (a ~75% gap)** |
| `05_build_disparity_by_year.py` | builds `data/conus_disparity_by_year.csv` (2015–2024) | instant | 10-row decade table |
| `06_plot_disparity_over_time.py` | plots the decade trend (exact-point; default window 2014–2023, `--start/--end` to change) | instant | **2.71 → 3.25× (+20%, peak 2023); 2015 minimum 2.22×; obs 3.8×** |
| `07_disparity_robustness_2023.py` | figure: 2023 disparity by method (2.5 / 3.0 / 3.25) | instant | `disparity_robustness_2023.png` |
| `08_coverage_radius_sensitivity.py` | 2023 farmland coverage at 500 m / 1 km / 2 km (Earth Engine batch export, 30 m) | ~10 min | **12.4% / 30.6% / 58.0% covered**; 1 km matches the manuscript's 30.5% |

**Headline reproduction (the paper's method):**
| Script | What it shows | Runtime | Expected result |
|---|---|---|---|
| `reproduce_disparity_pointmethod.py` | **single self-contained** end-to-end disparity, **30 m exact point** classification (GBIF + GEE) | **several hrs** (`--zoom 12`) | **~7.3% on ag; disparity ≈3.25×** — matches v1's 3.0 |

Run it with `--zoom 12` for the point method (matches the manuscript, ~19 m), or `--zoom 9` for the
fast ~137 m coarse cross-check (~2.5×). It is resumable and checkpoints to **local disk**
(`~/.csotf_pointmethod_ckpt/`, deliberately off the cloud-synced folder); the final number is
written to `outputs/pointmethod_2023_z12_RESULT.csv`.

Figures are written to `outputs/` (and paper figures also copied to `../figures/`). Step 02 saves
`data/obs_cells_2023.parquet`, which step 03 uses.

**Step 06 now plots the exact-point series**, reading `outputs/pointmethod_<year>_z12_RESULT.csv`
(one per year, written by `reproduce_disparity_pointmethod.py`) — it no longer depends on step 05.
Step 05 remains the fast coarse-grid decade table, kept as the conservative cross-check and for
provenance. All eleven years 2014–2024 have been measured; the manuscript series (2014–2023, ending on the year of the
full county analysis) is `outputs/pointmethod_disparity_2014_2023.csv`; the earlier 2015–2024 consolidation is kept alongside.

**The 2015–2016 dip is real, not a resolution artefact.** 2014 measures 2.71× at the exact-point method but 2.22× in
2015; a coarse-grid (`--zoom 9`) cross-check gives the same ordering (2014 2.39× vs 2015 2.01×, 2016 2.00×, 2017 2.19×;
`outputs/pointmethod_2014_z9_RESULT.csv`). Dataset composition does not explain it — eBird supplies ~94 % of records in
every year 2014–2017 and no farmland-heavy dataset enters in 2015–16 — so the transient rise in the farmland share of
observations lies within eBird's own spatial pattern. Endpoint framing therefore depends on the start year
(2014→2023: +20 %; 2015→2023: +47 %); the fitted linear trend (+0.087 per year, R² 0.72 over 2014–2023) is the robust statement.

## Data included (`data/`)
- `county_ag_area_2023.csv` — per-county farmland area (NLCD 2023). Land-cover input for step 3.
- `us_counties.geojson` — county boundaries (FIPS) for assigning observations to counties.
- `county_landcover_wide.csv` — **per-county `ag_<year>`/`land_<year>`/`ALAND`, 2015–2024** (USGS
  Annual NLCD 81+82). Land-cover input for step 05. (Provenance: `generators/`.)
- `county_obs_panel_long.csv` — **per-county `total_obs`/`obs_on_ag` per year, 2015–2024** (GBIF
  Maps API × NLCD overlay, the same overlay as step 02). Observation input for step 05.
  (Provenance: `generators/`.)
- `conus_disparity_by_year.csv` — the 2015–2024 CONUS decade series. **Regenerated by step 05**
  from the two panels above.

## Where the decade series comes from (full provenance)
`data/conus_disparity_by_year.csv` is **not** hand-entered — step 05 rebuilds it from the two
county panels, applying the exact same metric definitions as steps 01–03, per year:
```
export_county_landcover_panel.py ─┐  (NLCD 81+82, per county, per year)
                                  ├─► 05_build_disparity_by_year.py ─► conus_disparity_by_year.csv ─► 06_plot…
build_county_obs_panel.py ────────┘  (GBIF × NLCD overlay, per county, per year)
```
The two upstream harvest scripts live in `generators/` (the slow path back to the raw data
sources — you do **not** need to run them; the panels they produce are provided). See
`generators/README.md`.

Per-year definitions (identical to steps 01–03):
`pct_ag_area = 100·Σag/ΣALAND`; `pct_obs_on_ag = 100·Σ(obs_on_ag)/Σ(total_obs)`;
`disparity = pct_ag_area / pct_obs_on_ag` (>1 ⇒ farmland under-observed);
`pct_counties_underobserved = share of counties with per-county disparity > 1`.

## Pipeline validation (what was checked)
The decade pipeline was cross-checked and is internally consistent:
- **Grid ↔ panel.** Recomputing `%obs_on_ag` straight from the raw per-year overlay grids
  matches the per-county panel to within ~0.1–0.4 pp every year — the county roll-up does not
  distort the signal.
- **Regenerable.** `data/conus_disparity_by_year.csv` is reproduced **byte-for-byte** by
  re-running step 05 on the included panels (deterministic; no hidden state).
- **Sanity.** `%ag_area` is ~24% and nearly flat (land cover barely moves); `%counties
  under-observed` sits at ~76–78% every year; observations grow ~3.2× (44M→138M); the CONUS
  disparity rises monotonically in trend from ~2.01 (2015) to ~2.46 (2023).

**One honest caveat on absolute counts.** The GBIF density API returns slightly different totals
between harvest passes (records are continuously added/back-filled). So the `total_obs_millions`
column carries a few-percent absolute uncertainty, and re-harvesting via `generators/` will shift
it accordingly. The **ratio** metrics (disparity, %-on-ag, %-of-counties) are stable to that
drift, which is why the paper's claims rest on the ratios, not the raw counts.

## Note on the numbers — the two methods bracket the same finding by resolution
The manuscript's 2023 headline (**7.8%** of observations on farmland, **3.0×** disparity) comes
from **30 m exact point classification** (each observation classified by the NLCD pixel beneath
it) — the finest method. Steps 01–05 here use a **coarser ~137 m grid with fractional weighting**,
which gives farmland partial credit for observations on roads/farmsteads inside farm cells, so it
reports a higher on-farmland share (~9.5%) and a lower **~2.5×** disparity. That 2.5 is a
*conservative lower bound*, not a correction: disparity rises monotonically toward 3.0 as the grid
sharpens.

- `reproduce_disparity_pointmethod.py` — **single self-contained script** that reproduces the
  headline the manuscript's way (30 m point classification) end-to-end from GBIF + Earth Engine.
  At `--zoom 12` (~19 m, point-equivalent) it lands near **3.0**; at `--zoom 9` (~137 m) it
  reproduces the coarse **~2.5** cross-check. Full CONUS at zoom 12 is a multi-hour, resumable run.

See `../MANUSCRIPT_CHECKLIST.md` §A for exactly what to keep/refine in the text.

> NLCD version note: the scripts match the NLCD image by **year token only** (not a fixed version
> suffix), so they keep working after the sat-io asset is re-versioned — it went `C1V1`→`C1V2`
> since the first run. A re-run may therefore differ marginally from the original harvest; the
> ratios are robust to it.

## Resolution caveat to state in the paper
Observations are counted on a ~137 m grid and classified by the farmland fraction of each cell.
Because observers cluster on non-farmland micro-sites (roads, farmsteads) *within* farm cells,
this slightly **overstates** on-farmland observation — so the reported disparity is a conservative
lower bound (a ~19 m grid gives a marginally larger gap). This does not change any conclusion.
